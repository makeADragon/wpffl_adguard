! Title: wpffl - DNS 규칙 (AdGuard)
! Description: DNS 필터용 규칙. DNS 차단으로 깨지는 기능을 되살리는 허용(예외) 규칙. 브라우저 확장용 요소 차단은 adguard-general.txt / adguard-streaming.txt 참고.
! Homepage: https://github.com/makeADragon/wpffl_adguard
! Version: 2026.10.13
! Expires: 7 days
!
! 적용 대상: AdGuard DNS 보호(데스크톱) / AdGuard Home / AdGuard DNS(원격, adguard-dns.io)
! 참고: DNS 필터는 요소 차단(##)과 스크립틀릿을 지원하지 않는다. 호스트 단위 규칙만 동작한다.

! ===== 넷플릭스 (Netflix) =====
! ⚠ 아래2개 도메인은 넷플릭스 웹 플레이어의 "재생 진행/완료 보고" 엔드포인트다.
!   차단하면 '다음 에피소드 자동 재생'이 깨진다.
!
!   증상 : 2화 종료 → 3화로 넘어가지 않고 2화가 다시 로드됨 (모든 브라우저에서 동일)
!   콘솔 : "There was an error sending the data to CL Error: Send failed." 가 1초 간격 무한 재시도
!
!   원인 규칙 출처: AdGuard DNS filter
!     ||logs.netflix.com^
!     ||ichnaea-web.netflix.com^
!
!   실측(2026.10.13) : DNS 차단 해제 시 logs.netflix.com → http 400, ichnaea-web.netflix.com → http 200 으로 복구.
!   단, 재생 스트리밍 자체(www.netflix.com / nflxvideo.net)는 정상이라 영상은 재생된다는 것이 함정이다.
!
! ⚠ DNS 필터는 CNAME 체인 전체를 검사한다. 그래서 CNAME 대상도 함께 허용해야 한다.
!     logs.netflix.com        → logs.dradis.netflix.com        → logs.us-west-2.internal.dradis.netflix.com
!     ichnaea-web.netflix.com → ichnaea-web.dradis.netflix.com → ichnaea-web.us-west-2.internal.dradis.netflix.com
!   즉 아래2개만 허용하면 dradis.netflix.com 구간에서 계속 막힌다. dradis 를 통째로 허용해 체인을 커버한다.
@@||logs.netflix.com^$important
@@||ichnaea-web.netflix.com^$important
@@||dradis.netflix.com^$important
